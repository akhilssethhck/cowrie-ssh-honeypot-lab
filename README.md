# Cowrie SSH Honeypot Lab

A controlled cybersecurity laboratory project demonstrating the deployment, testing, and analysis of Cowrie, an SSH honeypot.

---

## Overview

This project demonstrates how an SSH honeypot can be deployed in a controlled laboratory environment to capture authentication attempts, commands, and SSH session activity.

The lab uses Kali Linux as the testing machine and Ubuntu/T-Pot with Cowrie as the honeypot environment.

The purpose of this project is to gain practical experience in honeypot deployment, Linux networking, SSH monitoring, log analysis, and security detection.

---

## Objectives

- Deploy an SSH honeypot
- Configure a controlled honeypot environment
- Perform SSH interaction from Kali Linux
- Capture authentication activity
- Capture command and session activity
- Analyze honeypot telemetry
- Identify potential attack indicators
- Document security findings
- Understand honeypot-based threat detection

Testing Methodology

The lab was conducted in a controlled virtualized environment.

A controlled SSH connection was initiated from Kali Linux against the Cowrie SSH honeypot.

Example:

ssh root@<HONEYPOT_IP>

The connection was successfully received by the honeypot and the SSH interaction was captured by Cowrie.

Commands and session activity were then reviewed to understand the type of telemetry generated by the honeypot.

SSH Activity

During testing, the following types of activity were observed:
